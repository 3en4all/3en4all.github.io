3EN Creator

Desktop short-form video workflow for authorized creators.

What 3EN Creator does

3EN Creator helps prepare short-form video content on the desktop and transfer an approved video to TikTok as a draft. The user then reviews, edits and decides whether to publish the draft inside TikTok.

The current TikTok integration does not automatically publish a public post. Draft upload and final publication remain separate user-controlled steps.

TikTok integration

3EN Creator uses TikTok Login Kit for OAuth 2.0 authorization and the TikTok Content Posting API for draft upload.

Login KitContent Posting APIuser.info.basicvideo.upload

user.info.basic is used to identify the authorized TikTok profile and display basic profile information. video.upload is used only to initialize and upload draft content requested by the authorized user.

User control

Authorization is granted by the TikTok user through TikTok's consent screen. 3EN Creator does not request or store the user's TikTok password. Access may be revoked by the user through TikTok's connected-app controls. Revoking access prevents future API use until the user authorizes the app again.

Data handling

OAuth access and refresh tokens are stored locally on the authorized desktop and are not committed to the public source-code repository. Basic TikTok profile data and API responses are used only for the authorized workflow. 3EN Creator does not sell TikTok data, use it for advertising, or provide it to data brokers.

Draft upload flow

  1. The user authorizes 3EN Creator with TikTok.
  2. 3EN Creator verifies the authorized profile and requested scopes.
  3. The user selects or approves a prepared short-form video.
  4. 3EN Creator uploads the file to TikTok as a draft.
  5. The user continues the editing and publishing flow in TikTok.
