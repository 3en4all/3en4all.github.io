3EN ContentPipeline — Privacy Policy

Last updated: September 24, 2026

1. Scope and operator

3EN ContentPipeline is a locally operated desktop application used by its operator to manage the production, review and controlled upload workflow for the 3EN4ALL YouTube channel. The API Client is not currently offered as a public hosted service.

2. YouTube API Services and Google OAuth 2.0

3EN ContentPipeline uses YouTube API Services and Google OAuth 2.0. Use of YouTube-related features is subject to the YouTube Terms of Service and Google's Privacy Policy.

The current OAuth scopes are youtube.readonly and youtube.upload. The application does not request, collect or store the user's Google or YouTube password.

3. Data accessed and stored

The application may access YouTube channel identification and basic channel information, video identifiers, video metadata, privacy/processing status and upload responses required to operate the authorized workflow.

OAuth credentials and authorization tokens are stored locally on the operator's computer. Locally stored workflow records may include a YouTube video identifier returned after an upload and local status/audit information associated with that upload. The application does not sell, rent or use YouTube API data for advertising or profiling.

4. Purpose of use

YouTube API data is used only to identify the authorized channel, verify access, upload videos explicitly approved by the user, and check or record the status of those actions. The current workflow requires review before upload and uploads are created as private by default.

5. Sharing

Data is sent to Google/YouTube only as necessary to perform actions requested through YouTube API Services. 3EN ContentPipeline does not provide YouTube API data to advertising networks, data brokers or unrelated third parties.

6. Revoking access and deleting authorized data

Access can be revoked through 3EN ContentPipeline's local disconnect/revoke function or through Google's permissions page at Google Security — Third-party access.

After revocation, locally stored OAuth authorization data and YouTube Authorized Data associated with that authorization are deleted as soon as possible and no later than 7 calendar days. Removing local application data does not delete content stored by YouTube; YouTube-hosted content must be managed through YouTube or an authorized client that supports that operation.

7. Security and retention

Credentials and tokens are kept locally and are excluded from the public source-code repository. Authorized Data is retained only while needed for the active authorized workflow and is removed when access is revoked or deletion is requested, subject to the 7-day maximum described above.

8. Contact

Questions or deletion requests relating to 3EN ContentPipeline can be submitted using the contact information available on 3en4all.github.io.
