3EN ContentPipeline — Terms of Service

Last updated: September 24, 2026

1. Purpose

3EN ContentPipeline is a local desktop tool for content preparation, rendering, quality control, metadata management, review and controlled YouTube upload workflows.

2. YouTube services

3EN ContentPipeline uses YouTube API Services. By using its YouTube-connected functionality, the user also agrees to the YouTube Terms of Service and acknowledges Google's Privacy Policy.

3. Authorization

YouTube access is authorized through Google OAuth 2.0. The application does not ask for or store the user's Google password. Authorization can be revoked at any time through the client or Google's account permissions.

4. User-controlled actions

The application separates preparation from approval and upload. A rendered item in READY state is not authorization to upload it. Upload requires explicit user approval and the current uploader creates approved uploads as private by default. Public publication is not performed automatically without a separate user decision.

5. Upload certification

By approving an upload, the user certifies that the content being uploaded complies with the YouTube Terms of Service, including the YouTube Community Guidelines, and with applicable copyright and other laws.

6. Responsibility

The user remains responsible for reviewing the video, title, description, rights status and publishing decision before approving an action that affects YouTube.

7. Availability

3EN ContentPipeline is currently a local development and internal-use tool. Its functionality may change as the software is tested and improved.

8. Privacy

Data handling for YouTube API Services is described in the 3EN ContentPipeline Privacy Policy.
