BlokerDanych

Lokalny anonimizator danych osobowych w PDF. Zaznacz, co ukryć, albo pozwól programowi wykryć dane, a potem zapisz dokument, z którego nie da się ich odzyskać.

A local personal-data anonymizer for PDF files. Mark what to hide, or let the program detect the data, then save a document from which it cannot be recovered.

WykryjDetect

Przycisk „Wykryj dane” znajduje dane osobowe w dokumencie. Kategorie wybierasz w panelu, każdą pozycję możesz odsłonić.

The “Detect data” button finds personal data in the document. You choose categories in the panel and can unmask any item.

Cover any area of a page by hand, including signatures, stamps or photos.

ZredagujRedact

Wynik jest składany z obrazów stron, bez warstwy tekstowej i metadanych. Zakrytego tekstu nie da się skopiować ani odczytać.

The output is rebuilt from page images, with no text layer or metadata. Hidden text cannot be copied or read back.

Jak działa BlokerDanych?

How does BlokerDanych work?

Wiele narzędzi „zaczernia” dane tylko wizualnie: czarny prostokąt leży na tekście, który nadal siedzi w pliku i da się go skopiować. BlokerDanych robi prawdziwą redakcję. Każda strona jest zapisywana jako obraz z naniesionymi zakryciami, a gotowy PDF nie zawiera warstwy tekstowej ani metadanych oryginału.

Wykrywanie obejmuje m.in.: osoby, PESEL, dowód osobisty, paszport, NIP, REGON, KRS, numery kont, telefony, e-maile, adresy, kody pocztowe, tablice rejestracyjne, księgi wieczyste, kwoty, daty i własne frazy. Dane w obrazkach i skanach program znajduje dzięki OCR: wbudowanemu w Windows albo Tesseract.

Many tools only “black out” data visually: a black box sits over text that is still in the file and can be copied. BlokerDanych performs true redaction. Every page is saved as an image with the covers applied, and the final PDF contains neither a text layer nor the original metadata.

Detection covers, among others: names, PESEL numbers, ID cards, passports, NIP, REGON and KRS numbers, bank accounts, phone numbers, e-mails, addresses, postal codes, licence plates, land-register numbers, amounts, dates and custom phrases. Data inside images and scans is found with OCR: built into Windows or Tesseract.

Wiele plików (Pro)Batch mode (Pro)

Przygotuj jeden dokument i zapisz go jako szablon. Potem zastosuj szablon do wielu plików: przejrzyj każdy po kolei albo zapisz wszystkie naraz z raportem, który zawiera tylko typy i liczby znalezionych danych, bez samych danych.

Prepare one document and save it as a template. Then apply the template to many files: review each in turn, or save them all at once with a report that lists only the types and counts of data found, never the data itself.

Dla kogo?Who is it for?

Dla każdego, kto udostępnia dokumenty z danymi osobowymi: biur rachunkowych, kancelarii, działów kadr, administracji i osób prywatnych wysyłających skany umów czy zaświadczeń.

For anyone who shares documents containing personal data: accounting offices, law firms, HR departments, public administration and individuals sending scans of contracts or certificates.

Ważne: automatyczne wykrywanie jest pomocą, nie gwarancją. Przed udostępnieniem dokumentu przejrzyj wynik i w razie potrzeby zakryj brakujące fragmenty ręcznie.

Important: automatic detection is an aid, not a guarantee. Review the result before sharing a document and cover anything missed by hand.
