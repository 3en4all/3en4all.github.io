Why is the download around 76 MB?

The Windows executable is distributed as a standalone package. It includes the application plus the components required to run it without installing Python separately.

  • • Python runtime
  • • PySide6 / Qt GUI libraries
  • • Email and HTML parsing components
  • • PDF report generation components
  • • Archive and file-format handling libraries
  • • Networking and security-related dependencies
