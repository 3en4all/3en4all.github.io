Jak działa Phishing Inspector?

How does Phishing Inspector work?

Phishing Inspector nie próbuje zastępować bramki pocztowej, programu antywirusowego ani analityka bezpieczeństwa. Jego zadaniem jest szybkie zebranie w jednym miejscu sygnałów, które podczas ręcznego sprawdzania podejrzanej wiadomości trzeba zwykle wyszukiwać osobno.

Silnik analizuje wiadomości .eml oraz .msg. Sprawdza m.in. nagłówki i ścieżkę Received, wyniki SPF, DKIM i DMARC obecne w wiadomości, zgodność domen nadawcy, podejrzane lub podobne domeny, adresy URL oraz załączniki. Dla plików wyliczany jest również skrót SHA-256, dzięki czemu wynik może być wykorzystany w dalszej analizie.

Poszczególne obserwacje są łączone w wynik ryzyka SAFE, SUSPICIOUS lub DANGEROUS. To klasyfikacja heurystyczna — wynik ma wskazać, które elementy wymagają uwagi, a nie udawać bezwzględnego werdyktu „phishing / nie phishing”. Raport wyjaśnia również prostym językiem, dlaczego dany sygnał podnosi lub obniża ocenę ryzyka.

Phishing Inspector is not intended to replace an email gateway, antivirus product or security analyst. Its purpose is to collect in one place the signals that normally need to be checked separately when reviewing a suspicious message.

The engine analyzes .eml and .msg messages. It inspects headers and the Received chain, SPF, DKIM and DMARC results present in the message, sender-domain alignment, suspicious or lookalike domains, URLs and attachments. SHA-256 hashes are also calculated for files so the result can be used in further analysis.

Individual observations are combined into a risk result: SAFE, SUSPICIOUS or DANGEROUS. This is a heuristic classification: it highlights what deserves attention rather than pretending to provide an absolute “phishing / not phishing” verdict. Reports also explain in plain language why a signal raises or lowers the risk score.

Testy i kalibracjaTesting & calibration

Przed publikacją ten sam produkcyjny silnik analizy został uruchomiony na zbiorze 6 691 wiadomości e-mail. Benchmark służył do obserwowania zachowania klasyfikacji na dużej próbce i do strojenia reguł tak, aby pojedynczy słaby sygnał nie powodował automatycznie alarmu. Nie jest to deklaracja „99,9% skuteczności” — zbiór testowy pomagał kalibrować zachowanie programu, ale nie reprezentuje każdego możliwego scenariusza phishingowego.

Before publication, the same production analysis engine was run against a dataset of 6,691 email messages. The benchmark was used to observe classification behavior at scale and tune rules so that a single weak signal would not automatically trigger an alarm. This is not a claim of “99.9% accuracy” — the dataset helped calibrate the application, but it cannot represent every possible phishing scenario.

Po co taki model?Why this approach?

Phishing rzadko daje się wiarygodnie rozpoznać po jednym elemencie. Legalna wiadomość może mieć nietypową trasę, a złośliwa może poprawnie przejść część kontroli uwierzytelniania. Dlatego program zestawia wiele niezależnych sygnałów i pokazuje ich kontekst. Użytkownik dostaje materiał do decyzji, a nie czarną skrzynkę z jednym procentem ryzyka.

Phishing rarely reveals itself through one reliable indicator. A legitimate message can have an unusual delivery path, while a malicious one may still pass some authentication checks. The application therefore combines multiple independent signals and shows their context. The user gets evidence for a decision rather than a black box returning a single risk percentage.

Ważne: wynik programu jest pomocą analityczną. Szczególnie w przypadku wiadomości dotyczących logowania, płatności, resetu hasła lub poufnych danych warto nadal potwierdzić żądanie niezależnym kanałem.

Important: the result is analytical support, not a guarantee. Messages involving login, payments, password resets or sensitive data should still be verified through an independent channel.

Dlaczego plik ma około 76 MB?

Why is the download around 76 MB?

Program jest dystrybuowany jako samodzielny pakiet Windows. Zawiera aplikację oraz komponenty potrzebne do uruchomienia bez osobnej instalacji Pythona.

The Windows executable is distributed as a standalone package. It includes the application plus the components required to run it without installing Python separately.

  • • Python runtime
  • • PySide6 / Qt GUI
  • • Parsery e-mail i HTMLEmail and HTML parsing components
  • • Generowanie raportów PDFPDF report generation components
  • • Obsługa archiwów i formatów plikówArchive and file-format handling libraries
  • • Biblioteki sieciowe i bezpieczeństwaNetworking and security-related dependencies
